# RootV3x portfolio — v7

## Inhoud
- Vijf beschikbare write-ups: Jerry, Cap, MetaTwo, Markup en Included.
- CTF in het hoofdmenu en een startknop bovenaan; inklapbare hints bij de flag checker.
- Vier flags leveren codefragmenten voor Final Access. De verborgen bestemming staat in shadow.html.

## Puzzels onderhouden
De vier antwoorden en bijbehorende fragmenten staan in script.js. De eindcode moet overeenkomen met deze vier fragmenten in volgorde. De trail gebruikt opmerkingen in de broncode van Jerry, Cap en MetaTwo. Houd deze drie pagina’s en shadow.html beschikbaar.

De terminal is een simulatie in de browser. De puzzels zijn bedoeld voor plezier en zijn geen toegangsbeveiliging: antwoorden in clientcode zijn te bekijken.
